## YSU Net v0.2.3

三平台桌面客户端与独立 Linux Python CLI 同步为 0.2.3，沿用原配置格式，不更换 0.2.1 正式更新信任锚。桌面认证仍由 Rust 执行，CLI 不作为桌面运行时。

### 认证与连接状态

- 补齐离线门户引导：精确匹配的 HTTP captive 入口通过一次匿名请求提取 HTTPS 门户提示；Location、HTML 静态导航与 Chromium 主文档共用校验，不关闭证书校验或放行任意 HTTP。可信旧主页面及 history 来源继续规范到 HTTPS。
- 校园门户 / CAS 域名解析失败时使用包内核验地址，仅替换 TCP 连接地址，保留域名、TLS SNI、证书校验和 Cookie 语义；Rust 也处理解析超时。自定义域名不套用校园地址，可选 Python 浏览器后端仍依赖正常 DNS。
- 验证码按所选密码表单判断，避免其他登录方式的隐藏控件阻断；服务返回 authResult 拒绝时立即停止，不继续提交上线。
- 增加独立只读状态观察和账户来源绑定，外部网络变化以新查询结果为准；账户信息与账号 / 服务不符时不展示为当前身份。
- 账号池保持先退出旧账号、登录目标账号、独立核验后提交配置的顺序；补齐切换阶段与失败恢复的固定诊断。缺失额度不触发自动换号。

### 验证与升级

新增直接调用共用 AuthClient 的无界面 Rust 探针和四目标 CI，便于定位门户导航而无需启动 GUI。其结果不替代原生安装、Chromium 或真实校园网验收。

21 的正式旧版 Shell 已完成离线登录、在线退出，以及移动 / 校园网账号的直接和守护双向切换；这些是 Shell 对照证据。新版本云端构建、真实 Rust 对照及未覆盖项目以[0.2.3 发布记录](https://github.com/wide-sky-with-me/ysu_net/blob/main/docs/desktop-release-0.2.3.md)为准，不将旧版成绩当作新 Rust 通过。

Windows / macOS 可主动检查更新或手工安装对应附件；Linux `.deb` 继续按系统包升级。差分仅在可信基线、平台及收益条件满足时提供，以本次公开清单为准；无可信缓存直接下载完整包。保留现有账号和偏好，不同时运行两套重连器。更新包签名不等于 Windows 发布者签名或 Apple 签名 / 公证；真实原位升级、失败回滚、物理断网与长稳运行仍须单独验收。

## YSU Net v0.2.2

本版将三平台桌面客户端与独立 Python CLI 同步为 0.2.2；CLI 不作为桌面运行时。重点修复检查更新崩溃、完善启动与状态反馈，并沿用原正式签名信任锚提供可选差分传输。正式发行状态与完整附件以对应 GitHub Release 为准。

### 主要变化

- 修复“检查更新”构建 HTTPS 客户端时未安装 TLS provider 导致的进程崩溃：初始化缺失的默认 provider，保留应用已选定的 provider 与系统代理兼容，不放宽 HTTPS、固定源或验签约束。
- 新增侧栏“关于”，集中软件更新、随包日志与公开项目资料；资料离线展示，不因打开页面抓取贡献者或检查更新。中性灰白 / 灰黑表面、字段对齐、连接光环和反馈浮层统一到当前界面，装饰不表示实时流量或认证成功回执。
- “检查更新”显示与原生检查同生命周期的旋转和终态浮层；读取状态、切回页面与被动事件不重播完成提示。下载、验签、还原和安装进度分别呈现，确认框保留键盘取消 / 焦点返回，减少动效不改变业务准入。
- 已确认在线时，连接标题与运营商选择同步实际服务；离线 / 未知保留配置意图，只读观察不回写配置或触发切线。设置保存使用明确的等待与回读确认，失败不闪成功；“自启后进入托盘”可独立选择，不因此启用原本关闭的自启或立即隐藏当前窗口，无托盘时显示窗口。
- 安装图标源改为与界面品牌一致的三节点 / U 形连线和默认蓝色底图；这里只记录 SVG 源变更，小尺寸清晰度、云端生成的 ICO / ICNS 及安装器 / 托盘实际视觉效果仍以最终构建和平台验收为准。

### 软件更新与迁移

- Windows x64 NSIS、macOS arm64 / x64 app archive 新增真正的差分传输；只还原完整安装载荷，不原位修补已安装目录，后续仍由官方安装器覆盖。原三个完整载荷、原公钥和受签名版本约束保留，**不更换 0.2.1 正式更新信任锚**。
- 有精确匹配的平台 / 包类型、版本、大小与摘要缓存，且补丁严格小于整包 80% 时才选择差分；补丁先由原公钥和受签名版本验证，解码还原后整包再次按原官方签名 / 版本验证。无可信基线首更直接新整包，不先拉旧包；差分下载、验签或还原失败只在下载阶段最多回退一次整包，安装失败不触发再次安装。缓存有独占与配额限制，完整说明见[更新指南](https://github.com/wide-sky-with-me/ysu_net/blob/main/docs/updates.md)。
- 0.2.1 正式客户端本身是整包更新器，不因新清单含差分就获得差分能力；0.2.1 → 0.2.2 首次升级仍按原整包方式。0.2.0 和使用旧信任锚的 0.2.1 候选须按[迁移说明](https://github.com/wide-sky-with-me/ysu_net/blob/main/docs/migration.md)手动安装正式版，不关闭验签或修改公钥绕过。
- Linux `.deb` 继续前往 Releases 按系统包方式手动升级，Python CLI 升级方式不变。只有主动检查并确认才下载 / 安装；Demo / 普通网页不执行真实更新。更新包签名不等于 Windows 发布者签名或 Apple 签名 / 公证。

## YSU Net v0.2.1

本版更新三平台桌面客户端与独立 Python CLI，版本均为 0.2.1；CLI 不作为桌面运行时。**旧 0.2.1 候选包需手动安装正式版并重启**，首次正式更新发行采用新的签名公钥基线；不要等待同版本软件内升级。0.2.0 首次升级也需手动安装。正式附件与发布状态以对应 GitHub Release 为准。

### 界面与账户

- 三平台共用界面改为圆润分层表面、紧凑连接主卡与胶囊控件，默认蓝灰白配色；保留六种主题色、明暗模式及已有有效偏好，窄屏自动重排。
- 新增页面进入、真实状态变化和完整数值的轻动效；相同快照不重复播放。正数流量的波纹仅为装饰，不代表额度比例、速率或正在传输；离屏、页面隐藏或开启减少动效时暂停。
- “在线信息”按账号身份与服务 / 地址组织，保留门户原字段、重复项和未知项；缺少账号时不从配置补造身份。桌面、CLI 与演示不再补造余额占位卡、金额或余额专属提示，门户实际返回的余额等条目仍原样展示；缺失剩余流量仍标为“门户未提供”，不当作零值或不限量。CLI 菜单同步整理分区与宽窄屏对齐。
- 托盘使用可打开主窗口的固定中文品牌标题与状态角标，真实状态 / 账号紧凑展示，IP 和最近结果收进连接详情子菜单，快捷操作、自动化与退出分组，确认离线使用语义红。继续使用系统原生菜单，不增加额外 WebView；动态状态使用普通菜单项，规避 GTK 图标项组合标签不随文字 setter 更新的问题，不改变认证、锁或退出语义。

### 查询与诊断

- 账户刷新在读取账户后独立复查连接状态，两段共用一次总超时。账户读取失败但独立查询确认在线时保留在线；复查失败或整体超时则为未知，仅独立证据可确认离线，不从账户缺项推断连接状态。
- 原生日志增加固定 `action / phase / code / operation / stage / reason` 分类，区分门户导航、会话、在线查询、账户与认证阶段，不传出底层任意错误、完整 URL、账号或 Cookie。`code=2` 仍是查询失败，不等于已经定位 DNS、TLS 或账号问题；“运行本地诊断”不发起登录。
- Rust 与 Python 的 API / 浏览器认证流程遇到门户流程节点外层或内层业务失败时停止，不继续提交上线操作。Windows 现场查询失败的根因仍需新分类日志确认，不能据此宣称已修复所有现场认证问题。

### 软件更新

- “设置 → 桌面”新增软件更新入口，仅用户主动检查、确认后才下载并安装，无启动自动下载或静默强制升级；Demo / 普通网页不执行真实更新。公开 0.2.0 没有此入口，首次升级到含入口版本仍须手动安装。
- 修复桌面“前往发布页”入口，由原生端打开固定官方 Releases 地址，不接受前端任意 URL；Demo 不打开外部浏览器，Linux `.deb` 保留手动下载入口。
- 使用官方 Tauri updater、内嵌公钥、固定本仓库 Release 源与受签名保护的版本绑定；这是签名完整包更新，不是二进制差分更新。更新源缺少 `latest.json` 时显示“更新源尚未就绪”，不误报已是最新版。检查或验签失败不会停止认证后台。
- 安装前拒绝与认证任务并发，并暂停本客户端任务而不主动下线、不改变账号或重连 / 自启偏好；安装失败尝试恢复同配置后台，恢复失败保持锁定，由用户重试恢复或退出重开。安装 / 恢复临界段与退出互斥，重启沿用启动时解析的绝对配置路径。
- Windows x64 使用当前用户 NSIS 更新包，macOS arm64 / x64 使用对应 `.app.tar.gz`；当前 Linux `.deb` 仍前往 Releases 手动升级，Python CLI 升级方式不变。更新包签名不等于 Windows Authenticode 发布者签名或 Apple 签名 / 公证，后两者本轮未提供。

### 验证与发布边界

修正了兼容浏览器验收对旧“离线模拟”横幅的依赖，改为验证 Demo 日志、禁用的更新入口、内存状态重置及普通网页的禁用控件。验收请求在发送前限制到预览服务的同一回环源，桥接测试确认 Demo 的认证与系统设置操作不调用原生 IPC，不依赖显眼横幅来证明安全。独立历史验收只代表各自源码与环境，不作为本版四平台通过声明。

## YSU Net v0.2.0

本版将桌面由 Qt 迁移到 Tauri，并保留独立 Python CLI。发布门槛为 Linux x64、Windows x64、macOS arm64 / x64 四个平台的构建、原生与安装验收全部成功；实际 CI 结果以对应运行为准。旧 `v0.1.0` 标签与 Qt 附件保留，不覆盖。

桌面客户端迁移为 Tauri 2 + Svelte + Rust，三平台共用界面与认证后台，不再依赖 Python、Node 或 Playwright 认证运行时。独立 Linux Python CLI 保留，版本同为 **0.2.0**；原 Qt 客户端（`ysu-gui`）停止维护。

### 主要变化

- 认证、自动重连、运营商切换与多账号热切换由 Rust 原生后台执行；登录、切换以独立查询确认，未知状态不自动登录。
- 可选零流量自动换号：仅门户连续报告零剩余流量时才尝试备用账号，缺失余量不猜测。CLI 同步提供多账号管理和热切换入口。
- 修复 Rust 只读查询中的旧门户 HTTP 导航：仅精确可信入口的同主机、受限路径 GET 引导规范到 HTTPS，不放宽通用 API / CAS / POST / TLS 边界。
- 账户页区分未知、确认离线、未读取和读取失败；失败显示公共错误与只读重试，成功清错，不伪造在线或离线。门户缺项继续显示“门户未提供”。
- 原生托盘、用户登录自启与共享浅色 / 深色界面；可选浏览器认证通过私有管道驱动本机 Edge / Chrome，不开放认证调试端口。

### 安装与升级

| 系统 | 附件与迁移 |
| --- | --- |
| Windows 10 / 11 x64 | NSIS 当前用户安装，无需管理员；先关闭旧 Qt 版自启并卸载旧 Inno Setup 版，两种安装器不会互相替换。使用系统 WebView2。 |
| Ubuntu 22.04 及更新，x86_64 | `.deb`，包名仍为 `ysu-net`；0.2.0 高于旧 0.1.0，使用 `apt install` 正常升级，无需 `--reinstall`。 |
| macOS 13.5 及更新 | arm64（Apple 芯片）和 x64（Intel）分别提供 `.dmg`，退出旧程序后拖入“应用程序”替换。 |
| Python / Linux 命令行 | 0.2.0 wheel、源码包，或按 README 从源码安装；不作为桌面运行时。 |

Windows / macOS 安装包未签名，系统可能提示未知发布者或要求在“系统设置 → 隐私与安全性”中确认。发布后按附件 `SHA256SUMS` 核对摘要。不要从旧 `v0.1.0` Qt 附件安装新版；完整说明见[迁移文档](https://github.com/wide-sky-with-me/ysu_net/blob/main/docs/migration.md#桌面-v020-升级)。
