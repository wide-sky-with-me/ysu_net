## YSU Net 图形界面客户端（测试版）

燕山大学校园网登录、运营商切换与自动重连的图形界面客户端，支持 Windows 和 Ubuntu。
**这是测试版，欢迎在校园网内试用并反馈问题。**

### 下载

| 系统 | 文件 |
| --- | --- |
| Windows 10 / 11（64 位） | `YSU-Net-*-windows-setup.exe`（推荐，约 34 MB），或免安装的 `YSU-Net-*-windows-portable.zip` |
| Ubuntu 22.04 及更新 | `ysu-net_*_amd64.deb`（约 55 MB），或 `YSU-Net-*-linux-x86_64.tar.gz` |

**Windows**：双击安装，不需要管理员权限。安装包没有代码签名，SmartScreen 提示“已保护你的电脑”时，点“更多信息 → 仍要运行”。

**Ubuntu**：`sudo apt install ./ysu-net_*_amd64.deb`，然后在应用列表里打开 “YSU Net”，或在终端运行 `ysu-gui`。

### 请帮忙测试（需要在校园网内）

1. 在“设置”里填写校园网账号密码并保存。
2. “概览”页点击“连接”，确认显示“已连接”、IP 和运营商。
3. “账户”页查看剩余流量与余额是否与门户一致。
4. 点击“断开连接”，确认显示“未连接”。
5. 在线时切换运营商（例如校园网 → 中国移动），确认切换成功。
6. 开启“自动重连”，手动断网或在门户下线后，确认会自动重新登录。
7. 可选：开启“登录系统后自动启动”，重启电脑确认自动联网。
8. 可选：在“设置 → 认证方式”选择浏览器认证（首次会下载约 30 MB 组件），再测试一次登录。

### 反馈

请在 [Issues](https://github.com/wide-sky-with-me/ysu_net/issues) 中说明：系统版本、使用的运营商、操作步骤、看到的提示，以及“日志”页的内容（点击“复制”）。
日志只记录操作结果和错误提示，不包含密码；错误信息里可能出现本机文件路径，公开前可自行检查。

### 已知限制

- 这是测试版，尚未在所有运营商和网络环境下验证。
- Ubuntu 上的浏览器认证需要安装 .deb 版的 Chrome 或 Edge（Snap 版 Chromium 与 Firefox 不可用）。
- 需要在未登录系统时也保持在线的 Linux 设备，请使用命令行版（见 README）。
