# 2026-10-25 主连接图标在线动效验收

[现行界面规则与参考源码](rust-desktop-design.md) · [共用动效生命周期](../desktop/src/lib/motion.ts) · [浏览器回归](../desktop/tests/connection_motion_preview.py)

用户要求圈出的主连接图标增加 FlClash 风格动感。本轮只为核心确认在线的主图标添加双层细环扩散：周期 2.8s、错开 1.4s、最大比例 1.44；绿色勾号本体、文字、卡片保持不动。离线/未知不循环，普通刷新或排队回执不改变在线判定、不重启已有循环；侧栏仍仅保留原有 450ms 状态变化反馈。

实际核对本地官方 FlClash 参考修订 `8d4f9744948751f1273fe871e1d05276fac09b0e`，其指定状态控件使用 circle/cookie 形变与短回弹。这里独立适配双环而不复制 Flutter 实现、图标或隧道功能，不声称原版存在相同的在线持续水波。旧“连接图形不持续呼吸”规则仅在本次主图标范围被替代。

扩散层仅使用绝对定位的装饰伪元素，不加入正文、控件或额外说明。复用 `ambientMotion` 的 IntersectionObserver、文档可见性及减少动效监听；离屏/隐藏暂停、减少动效静态、销毁断开监听，无轮询或新依赖。

## 实际验证

- 前端检查无错误/警告，213 项单测通过，生产前端构建成功。
- 新回归确认双环实际时间推进、透明度/缩放相位变化，跨完整周期逐帧测量图标本体、SVG、标题和卡片几何不变；同值快照、900ms 只读忙碌查询均不重启动画对象或时间线。
- 离线/未知无循环，确认状态变化的原有 450ms 动效仍在；默认与动态减少动效静态，实际页面滚动离屏暂停并继续原相位，三次切页销毁/重建不叠加。页面隐藏覆盖通过测试端属性与 visibilitychange 模拟，**不代表真实操作系统最小化验收**。
- 明暗×六种强调色×320/390/700/1000 宽度共48组保持语义绿色、无溢出、装饰不跨入标题。圆润界面、多账号、原有桌面、反馈浮层和配色回归通过；原有按压、密码清理、忙碌停止与确认框断言保留。
- 首次启动测试预览目录错误导致404，改为 desktop 工作目录后继续；清理诊断不再覆盖原始失败。新脚本最初误假设窄屏由 main 滚动，按实际 CSS 改用 document.scrollingElement，仍执行真实滚动与离屏暂停断言。旧圆润测试的有限动画等待只认识流量循环，现另精确允许主图标上名为 connection-ripple 的无限动画，没有放行任意持续动画或删除断言。
- `git diff --check`、社区检查及受影响文档链接检查通过；CI 增加新回归定义，本轮不声称远端 CI 已执行。

成功报告、明暗截图、轻环关键帧和真实浏览器帧编码短片在 `dist/connection-motion-20261025/accepted-v3/`；其裁剪 GIF 是展示片段，完整 WebM 保留源帧时间记录。所有截图/视频仅用固定的空账号/IP离线夹具，不取用户截图中的私人值。失败记录保留在 accepted、accepted-v2 与 rounded，复测圆润结果在 rounded-v2，其余结果见各套件目录。
