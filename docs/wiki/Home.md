# ysu-net 使用导航

社区维护的燕山大学校园网管理工具，提供 Linux 命令行与 Windows / Ubuntu 桌面客户端。本页是入门导航，详细行为以安装版本对应的文档为准；本项目不是学校或运营商的官方服务。

## 先分清版本

`main` 已整合命令行与桌面代码，发布基线为 [v0.1.0](https://github.com/wide-sky-with-me/ysu_net/releases/tag/v0.1.0)，包含自动重连状态刷新修复。从源码复现发布版使用对应标签；开发以 `main` 为基线。旧测试标签与源分支保留，不代表新版仍缺少桌面入口。

安装和本地诊断可在校外完成，登录与校园网状态查询需要接入校园网。API 是默认认证方式，浏览器方式是可选能力。缺少流量字段时显示“门户未提供”，不代表额度为零或不限量。
