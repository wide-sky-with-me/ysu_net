# 桌面链路调试记录

[返回首页](../README.md) · [文档导航](README.md) · [桌面运行说明](tauri-desktop.md) · [常见问题排障](wiki/Troubleshooting.md)

当在特定网络环境下遇到偶发登录失败或重定向异常时，可在桌面客户端「日志」页开启**本地链路调试记录**，在复现问题后导出脱敏的诊断事件文件用于排障。

---

## 使用步骤

1. 打开桌面客户端的 **日志** 页，点击 **开始调试记录**，等待状态显示为“正在记录”。
2. 执行需要排查的操作（如点击 **刷新状态**、**立即连接** 或 **断开连接**）。
3. 复现完成后，回到 **日志** 页点击 **停止记录**，再点击 **打开记录目录** 即可找到生成的 `.jsonl` 诊断文件。
4. 客户端重启后调试记录默认恢复为关闭状态。

---

## 文件位置与记录范围

- **存放目录**：默认位于主配置文件同级的 `config.diagnostics` 目录下，单文件上限 `8 MiB`，最多自动保留最近 5 份记录文件。
- **记录内容**：
  - 客户端版本、系统平台、架构与事件时间戳；
  - 桌面任务类型（手动连接、自动重连、后台观察、账号切换）；
  - 认证阶段（`portal_navigation`、`cas_login`、`service_login`、`verification` 等）与 HTTP 状态码、响应字节数；
  - 发生网络异常时的阶段分类（`send` / `read_body`）与系统 I/O 错误类别。
- **隐私保护**：调试记录**不会**写入学号、密码、设备 IP/MAC、Cookie、票据参数、完整 URL 查询串或门户响应正文。公开分享前仍请按 [公开反馈的脱敏清单](security.md#公开反馈的脱敏清单) 复核。
