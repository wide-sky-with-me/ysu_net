# 2026-10-25 刷新稳定性与通知浮层验收

[当前界面规则](rust-desktop-design.md) · [桌面运行语义](tauri-desktop.md)

## 复现与实现

用户报告首页点击刷新时内容闪动并短暂出现蓝字。在原生产前端、1000×720、全模拟原生 IPC、900ms 查询夹具下逐帧复现：`main` 的 Y 从 **88→118→88px**，连接主卡、自动化和控制卡均随之上下跳 **30px**。原因是全局 `.busy-line` / `.notice` 插入和移除时参与正文 flex 布局；不是门户数据证据或运营商切换问题。原始坐标及无私人账号/IP的前中后截图保留在 `build/feedback-20261025/before/`。

[FeedbackDock](../desktop/src/components/FeedbackDock.svelte)将全局进度与结果改为不占正文位置的非模态气泡，桌面位于右上角刷新按钮旁，窄屏用底部浮层。图标、短消息和关闭入口在同一行，不加重复标题或全页遮罩；刷新按钮按真实忙碌状态即时显示进度，不由气泡延时控制禁用。

[时序控制器](../desktop/src/lib/feedback.ts)只处理呈现：加载延迟 250ms，快速查询不会闪现气泡；成功提示 4500ms 后关闭，悬停或键盘焦点停留时暂停剩余计时；错误不自动消失。对象身份和版本保护防止重复快照续期、旧计时器关闭新消息或销毁后回调。进度结束不会生成“成功”，查询排队确认不当作完成。字段错误、账户读取状态、下载进度仍在各自上下文中，认证、队列、停止与退出逻辑未改。

## 实际检查

- 前端检查无错误/警告，**213 项单测通过**；其中新增[反馈控制器测试](../desktop/src/lib/feedback.test.ts) **26 项**，覆盖时序、暂停/恢复、过期身份、重入、替换和销毁。
- [反馈浏览器回归](../desktop/tests/feedback_preview.py)用 80/900ms 夹具逐 requestAnimationFrame 采样；快速/慢速状态与账户刷新、重复刷新、保存和失败均验证正文/卡片几何偏差不超过 1px，未放宽原标准。忙碌结束不凭空报成功，保存结果不会堆叠或被旧计时器提前关闭，错误超过成功消息寿命仍保留，可用键盘关闭。
- 明暗×1000/700/390/320 宽度无横向溢出、浮层不越出窗口；减少动效静态、普通动效路径、真实忙碌禁用与既有模拟多账号停止控件均有断言。只有显式通知进入屏幕阅读状态/错误通道，不抢正文焦点。
- 兼容冒烟、原有桌面、多账号、圆润界面、关于页和六色明暗审计通过；多账号原来绑定 `.busy-line` 的断言迁到实际浮层，仍保留“正在切换账号”、旧观察未被确认覆盖以及忙碌时可停止的全部断言。
- 首次新回归全部功能断言通过，但网络栅栏误拒绝 Chromium 分类为 `other` 的站内 `/favicon.svg`。保留失败报告后，单独验证其精确路径与 GET，再仅放行 HTML 明确声明的同源、无查询串/片段 favicon；并未放行任意 `other`、fetch/XHR、WebSocket、外部来源或其他回环端口。修正后完整反馈回归通过。
- `git diff --check`、社区检查及受影响文档的本地链接/锚点核对通过；[CI](../.github/workflows/tauri.yml)新增此回归定义，本轮不声称远端 CI 已运行。

反馈失败报告在 `dist/feedback-20261025/accepted/`，修正栅栏后的结果在 `accepted-v2/`，最终阴影/旋转中心微调后重新构建并验收的报告与截图在 `dist/feedback-20261025/final/`。均使用全模拟 IPC 或原有离线 Demo，没有真实门户操作或用户截图中的私人数据。

## 范围边界

本轮只改共用桌面反馈呈现，不改认证/查询业务、CLI 输出、原生更新或签名信任。Windows/macOS/Linux 共用前端；没有执行真实原生窗口、重建原生包或跨平台现场验证，未重新跑无业务改动的 Rust 测试。当前安装版仍保持此前版本，需用户另行确认才退出并同步安装。

没有真实登录、下线、物理断网、在线升级、提交、推送或正式发布。源码修复与浏览器回归不代表正在运行的客户端已经更新。
