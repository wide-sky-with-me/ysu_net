## 尚未证明的范围

源码共用、CI 构建、离线浏览器夹具、原生 Demo、手动重装和正式发布分别是不同证据。0.2.3 的[共用 Rust 认证库](desktop-release-0.2.3.md#修复后的真实验证)已在 21 完成真实登录 / 下线及独立核验，Windows 原生探针完成无凭据查询；Shell 账号池另有真实切换记录。Windows GUI 离线登录、Rust Worker 真实换号、真实零流量轮换、物理断网、长稳、系统登录自启及 Windows / macOS 软件内原位升级与失败回滚仍需单独验收；公开包验证也不表示本机已安装。各阶段细节以原文为准，不从按钮、流程定义或同版本号推断已经通过。
