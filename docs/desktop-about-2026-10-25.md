## 本次范围

用户要求移除认证参数页常驻的“保存后下次操作生效”文字，并补齐可见的软件更新、更新日志、GitHub 与贡献者入口。用户已明确选择沿用**签名整包在线覆盖升级**，不实现二进制差分增量。

[主界面](../desktop/src/App.svelte)新增侧栏“关于”和 Ctrl/Command+5 导航，将既有更新面板从外观设置底部移到[关于页](../desktop/src/components/AboutPage.svelte)。未保存反馈仍按实际修改显示，保存成功仅提示“参数已保存”；保存按钮继续右对齐，未改变参数生效或证书确认语义。

## 来源与安全

- 更新日志只派生 [release-notes.md](../packaging/release-notes.md)，以普通转义文本展示；没有新增并列维护的日志或改写已发布条目。
- 公开贡献者使用[有时间和来源的离线快照](../desktop/src/lib/project-info.json)，只显示实际公开账号，不推导邮箱、虚构身份或加载网络头像。详情及客户端路由见[项目信息模块](../desktop/src/lib/project.ts)。
- 项目外链只接受[原生固定字符串目标](../desktop/src-tauri/src/project.rs)，拒绝任意 URL、程序及对象参数。Demo 在客户端和原生端均阻断打开浏览器；原生失败不传系统异常。发布页继续复用现有无参数命令。
- 打开“关于”只读取更新状态，不检查、下载或安装。现有签名、公钥、版本绑定、忙碌准入、暂停与恢复机制未改。

公开核对由匿名 GitHub API 于 2026-10-25 执行：最新正式版仍为 v0.2.1；Release body 与该标签下的发布说明一致，而公开 main 分支同路径仍只有 v0.2.0。当前 feed notes 只是发布说明占位文字，不能拿它或默认分支替代随包完整日志。名单来源、时间和分页状态保留在上述快照中，不保存私人作者邮箱或凭据。

## 未执行与发行边界

本轮仅开发与测试，**未关闭、卸载或更新用户当前安装版，未改用户配置、未提交推送或正式发布**。当前工作树仍是 0.2.1 本地未发布改动；同版本不代表与正式附件同一构建。这些新界面不会自动出现在已安装版，也不能通过同版本在线更新获取。
