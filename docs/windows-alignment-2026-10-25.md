# 2026-10-25 在线信息对齐修复与本机更新

[现行设计规则](rust-desktop-design.md) · [Tauri 桌面说明](tauri-desktop.md)

用户截图报告账户页的字段图标只贴着标签一行，与下方数值组成的文字组不居中。用户确认“同步更新本机”后，构建并卸载重装 Windows 本地修复包；保持所有账号和外观偏好不变，未提交、推送或正式发布。

## 实现与复现

[共用样式](../desktop/src/app.css)将每个在线字段改为固定图标列与文字列：图标相对“标签＋数值”整体居中，标签和数值共用左边线，不再用数值左边距模拟缩进。保持原有两列、定义列表语义、字段名称/原值和自动换行；不改业务逻辑、主题色或 Rust 数据处理。

[布局回归](../desktop/tests/rounded_desktop_preview.py)新增真实边界框断言，要求图标中心与文字组中心、标签与数值左边线偏差均不超过 1 CSS 像素，图文间距至少 10 像素。原构建确实失败：中心偏差 **14px**、间距 **8px**；修复后偏差 **0px**、间距 **12px**，未放宽断言。
