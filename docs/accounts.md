# 多账号与流量换号

[返回首页](../README.md) · [CLI 使用](usage.md) · [Rust 图形版](tauri-desktop.md) · [设计决定](../.agents/notes/proposals/accounts/2026-10-14-account-rotation.md)

适用于 `feat/rust-desktop` 开发版，尚未发布。Rust 图形版与 Python CLI 使用相同账号簿；两者仍分别运行自己的认证实现，不同时争用同一配置的认证锁。

## 图形版

在“设置 → 校园网账号 → 保存的账号”新增账号，为每个账号设置名称、用户名、密码、运营商和认证方式。创建后用户名固定，修改密码可留空保留；当前账号先切换再删除。原来的单账号表单仍用于修改当前配置。

在“连接 → 连接账号”选择备用账号，点击“切换账号”并确认。网络会短暂中断。收到请求只表示排队，界面上的实际账号和服务更新后才表示核验成功；切换失败会在状态可信且原配置未改变时尝试恢复原连接。

先开启“自动重连”，再开启“自动换号”。需要当前账号及至少一个启用且有密码的备用账号。关闭自动重连或下线同时关闭自动换号；忙碌时仍可关闭或退出。切换已经开始时，原连接可能已经下线，取消后请刷新实际状态。

## Shell 版交互菜单

安装后的 `ysu` 是 Shell 包装入口，认证与守护继续使用同一套 Python 实现。运行 `ysu`，选择主菜单 **16 多账号与自动换号**；也可直接运行 `ysu accounts` 或 `ysu accounts menu`。

子菜单展示当前配置账号、保存的备用账号和自动换号配置；进入或刷新列表不联网、不迁移密码。**2** 新增账号，**3** 编辑，**4** 核验热切换，**5** 删除，**6** 启用/停用候选，**7/8** 开启/关闭自动换号，**9** 查询账户与剩余流量。这里的编号属于账号子菜单，主菜单 **4** 仍是下线断网。

密码通过终端隐藏读取，编辑留空保留；换号和删除需再次确认。启停候选只改变其可切换状态，保留密码与当前连接。当前账号先切换后再删除；新建账号不会直接替换当前配置。子菜单 **0** 返回主菜单或结束直接调用，不停止后台或下线。

自动换号默认关闭。先配置当前账号并保存有效备用账号，再从主菜单 **3** 或 `ysu on` 启动自动重连，然后在账号子菜单 **7** 确认开启；此开关本身不会启动后台服务。无 systemd 时，在另一终端使用同配置路径运行 `ysu daemon`，再打开账号菜单。已有守护时换号交给其串行核验，不必重启服务。

## 命令行子命令

```bash
ysu accounts list
ysu accounts save 备用用户名 --label 备用账号 --service 中国移动
ysu accounts list --raw
ysu accounts switch 账号ID
ysu accounts save 备用用户名 --id 账号ID --label 新名称
ysu accounts save 备用用户名 --id 账号ID --disabled
ysu accounts save 备用用户名 --id 账号ID --enabled
ysu accounts delete 账号ID
```

`save` 在交互终端隐藏读取密码，不把密码放在参数中。更新时空密码保留原值。账号 ID 来自列表，不是用户名；`current` 是尚未正式保存的当前配置占位项。删除仅针对非当前保存项，用户名变更使用新增账号。

后台 `ysu daemon` / systemd 守护运行期间，`accounts switch` 经私有控制通道交给锁所有者串行执行，不先停止守护，也不从 CLI 并发登录。成功响应包含独立核验及活动配置保存；通道忙碌、旧所有者不支持、超时或未确认均返回错误，不冒充成功，也不绕开运行锁。旧 Qt 兼容引擎开启自动管理时同样消费该通道；旧 Qt 不新增账号簿视觉界面。

```bash
# 已有至少两个有效账号，且守护正在运行：
ysu accounts rotation on
ysu accounts rotation off
```

CLI 轮换依附正在运行的守护/Qt 自动管理，不额外启动第二个后台进程。一次性切换不要求开启轮换。原来的 `ysu switch 中国移动` 仍表示同账号运营商切换，沿用其旧互斥要求，不混同 `accounts switch`。

Rust 图形版不消费 Python 文件控制通道。其后台正在持锁时，CLI 的账号切换不会越过该所有者；在图形版中切换，或退出图形版后由 CLI 接管。反之，外部守护正在管理配置时，图形版显示外部管理，不并发接管。

## 自动触发依据

默认关闭。只检查配置所属的在线账号，读取流量前后核验同一账号和运营商。检查间隔至少一分钟；相隔至少一分钟的连续两次有效查询都明确报告零剩余流量，才尝试一个备用账号。只接受原始账户条目中的“剩余流量”及显式单位，不从余额、已用流量、登录错误或断网猜测。

缺失、裸零无单位、负数、重复冲突、未知单位、HTTP/业务失败、身份改变或无限量均不触发。显示零记为 `zero_reported`：门户可能四舍五入，所以它是“门户报告零”，不是精确字节耗尽证明。门户未提供流量时仍可手动热切换，自动模式保留当前账号。

按保存顺序选择下一个有效启用账号，不为探测候选额度反复下线。已报告零或切换失败的账号冷却至少十五分钟；全部候选停用或冷却时等待后续检查，不循环登录。凭据变更或显式手动切换可重新尝试。新账号登录成功只证明实际连接成立，不证明其剩余额度充足；下一轮继续查询。

## 保存与兼容

活动账号仍保存在原 `config.json`；账号簿为同配置路径替换扩展名的 `config.accounts.json`，自定义配置互不混用。最多保存 32 个账号，账号簿上限 64 KiB。使用同一短配置写锁与私有原子替换；密码不进入公开快照或 CLI 列表。Windows 文件访问权限继承用户配置目录，Unix 文件为 `0600`。

查看旧配置不会立即迁移或写入密码。保存或离开旧账号时才正式入簿，旧 CLI/Qt 对当前密码和运营商的修改优先于账号簿旧镜像。当前配置缺少凭据时先在原账号表单补齐，不回填账号簿旧密码。目标账号及服务独立核验后才提交活动配置；同时更新的无关计时参数保留，身份、地址或目标凭据冲突会停止提交。账号簿元数据写入失败不等同活动配置回退，错误后重新查看实际状态与配置。

`YSU_USER`、`YSU_PASS`、`YSU_SERVICE` 临时覆盖期间停用账号切换与开启轮换，避免把临时凭据隐式保存进账号簿。原单账号命令仍保留环境覆盖语义。回退旧发行版仍能读取活动配置，但旧二进制不会理解新账号簿或控制通道。

普通卸载保留活动配置及账号簿；显式 `uninstall.sh --purge` 同时删除两者，原有运行锁保护仍生效。

Shell 菜单、真实包装脚本及终端输入验证见 [Shell 验收记录](shell-accounts-validation.md)；此前桌面与共享核心的验证见[账号轮换验收记录](account-rotation-validation.md)。共同规则由 [Python 账号存储](../src/ysu_net/manager/accounts.py)、[原生账号存储](../desktop/src-tauri/src/accounts.rs)及[共享流量样本](../tests/fixtures/account-quota.json)约束。
