# 多账号池、流量换号与无感联动

[返回首页](../README.md) · [文档导航](README.md) · [命令与配置](usage.md) · [桌面客户端指南](wiki/Desktop-Client.md)

当拥有多个校园网账号（或同一账号下不同运营商方案）时，**YSU Net** 支持通过**多账号池**统一保存凭据、按优先级排序、一键热切换账号，并在当前账号剩余流量归零时**自动切换到下一可用账号**。

同时，多账号池与 **7 天无感认证及自动续约**深度联动：支持为不同账号独立维护无感续约，并在换号时自动完成本机无感认证的解绑与重绑交接。

---

## 快速上手

### 桌面客户端

1. 打开侧栏 **设置 → 账号**（或在 **连接** 页点击账号区的「管理账号池」）。
2. 点击 **新增账号**，填写账号标识（或留空自动生成）、备注名称、学号、密码、运营商与优先级，保存即可。
3. 在 **连接** 页的「多账号池」下拉框中选择目标账号并点击 **切换账号**，客户端会自动下线旧账号并登录新账号。
4. 若希望流量用尽后自动切号，在 **连接** 页开启 **自动重连** 与 **零流量自动换号**。

### Linux 命令行 (`ysu account`)

```bash
# 1. 添加备用账号到账号池（不填 -p 会安全提示输入密码）
ysu account add -u 20260001 -s 中国移动 --name "主力移动" --priority 10
ysu account add -u 20260002 -s 中国联通 --name "备用联通" --priority 20

# 2. 查看账号池列表与自动换号状态
ysu account list

# 3. 立即切换到指定账号（支持填账号 ID、备注名称，或唯一学号）
ysu account use "备用联通"

# 4. 开启零剩余流量自动换号
ysu account auto on
```

## 账号池管理命令

| 命令 | 说明 |
| --- | --- |
| `ysu account list [--json]` | 列出全部已保存账号、启用状态、优先级、当前活动标记与最近流量状态 |
| `ysu account add -u 学号 [-s 运营商] [--name 备注] [--priority 数字]` | 新增账号；加 `--use` 可在保存后立即切换为当前账号 |
| `ysu account edit <标识> [...]` | 修改指定账号的备注、学号、密码（`-p` / `--prompt-password`）、运营商或优先级 |
| `ysu account use <标识>` | 将目标账号设为当前活动账号；若当前在线或守护运行中，立即执行下线重登热切换 |
| `ysu account enable <标识>` / `disable <标识>` | 启用或停用某个账号参与自动轮换（当前活动账号不可直接停用） |
| `ysu account remove <标识>` | 从账号池删除非活动账号 |
| `ysu account auto [on\|off\|status]` | 开启、关闭或查看「零剩余流量自动换号」状态 |

- **排序规则**：候选账号按 `priority` 从小到大排序（默认 `100`）；优先级相同时按添加顺序排列。
- **重名区分**：当多个条目使用同一学号但配置了不同运营商时，请使用各自的账号 `id` 或唯一备注名区分。

## 零剩余流量自动换号规则

开启「零流量自动换号」后，后台会在保持在线期间定期查询当前账号的套餐流量：

1. **触发条件**：仅当确认当前账号在线、身份与配置一致，且门户返回的**剩余流量等于 `0`** 时，才会触发自动换号。
2. **安全保守策略**：
   - 校园网不限量套餐、门户未返回流量字段、或网络波动导致查询失败时，**不会**误判为零流量，也不会触发换号。
   - 关闭「自动重连」或手动执行下线时，自动换号会同步关闭。
3. **轮换与回退**：
   - 触发换号后，按优先级依次尝试已启用的候选账号。
   - 若某个候选账号登录失败，或登录后发现其剩余流量同样为 `0`，会自动跳过并继续尝试下一个候选账号（本轮内不会重复尝试已耗尽账号）。
   - 若所有候选账号均不可用，客户端会自动尝试恢复原账号连接并记录告警日志。

## 与 7 天无感认证的协同联动

在校园网环境中，如果某台设备（MAC 地址）在门户开启了 **7 天无感认证**，校园网关会直接将该 MAC 绑定到开启无感的账号上。如果不先解绑无感认证就直接切换账号，网关仍可能把该设备识别为旧账号。

为此，YSU Net 对多账号池与无感认证做了两项核心联动：

### 1. 换号时自动交接本机无感认证

无论是手动切换账号（桌面端「切换账号」或 `ysu account use`），还是后台因零流量触发自动换号，只要旧账号与新账号不是同一个学号：

1. **下线前自动解绑**：客户端在下线旧账号前，会先查询旧账号的自助服务；若发现本机 MAC 在旧账号下开启了无感认证，或旧账号配置了针对本机 MAC 的自动续约规则，会先自动解绑旧账号上的本机 MAC 无感记录。
2. **上线后自动接力**：新账号成功登录并确认在线后，客户端会自动在新账号下为本机 MAC 重新开启 7 天无感认证（默认上网服务同步为新账号所选运营商），并将本机自动续约规则平滑迁移到新账号名下。
3. **容错不阻断**：如果自助服务门户暂时繁忙导致无感交接未完成，账号本身的 Portal 登录切换仍会正常生效，不会阻断正常上网。

### 2. 多账号独立无感自动续约

如果你有多个账号分别给不同设备（例如账号 A 绑定笔记本、账号 B 绑定平板或路由器）开启了无感认证，可以为每个账号独立开启自动续约：

- **命令行**：在任意 `ysu self` 命令后加上 `--account <标识>` 即可操作对应账号：
  ```bash
  # 查看账号池中 backup 账号的设备与无感状态
  ysu self list --account backup

  # 为 backup 账号下的指定设备开启独立自动续约
  ysu self renew on --account backup --mac AA-BB-CC-DD-EE-FF --service 中国移动
  ```
- **桌面端**：在侧栏 **设备** 页顶部的「查看账号」下拉框中切换账号池条目，即可分别查看和管理各个账号的在线设备、无感认证开关与自动续约设置。
- **后台轮询**：守护进程与桌面后台会遍历 `config.nosense.json` 中所有启用了 `auto_renew` 的账号，使用各账号独立隔离的凭据与会话缓存分别检查到期时间并自动续期，互不干扰。
